# Ювелірна майстерня "Dora": семантична сторінка з навігацією та картками

## Мета

Побудувати невелику семантичну сторінку з навігаційним меню та трьома картками послуг і закріпити базове розмежування завдань між Flexbox (одновимірні ряди) та CSS Grid (сітка карток).

## Використані технології

- семантика HTML5: `header`, `nav`, `main`, `section`, `article`, `footer`;
- BEM-іменування класів (`card`, `card__title`, `card--accent`), стилі не прив'язані до тегів;
- Flexbox для навігаційного меню (вирівнювання та відступи через `gap`);
- CSS Grid для карток (`grid-template-columns: repeat(3, 1fr)` та `gap`);
- `min-width: 0` та `overflow-wrap: anywhere` для стійкості до довгих заголовків.
